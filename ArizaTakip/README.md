# 🛠️ Arıza Takip Sistemi

Teknik destek süreçlerini kolaylaştırmak ve arıza kayıtlarını düzenli bir şekilde takip etmek amacıyla geliştirilen bir uygulamadır.

## Özellikler

- Arıza kayıtlarını listeleme
- Arıza detaylarını görüntüleme
- Yeni arıza formu
- Arıza durumlarını görüntüleme

## Kullanılan Teknolojiler

- React Native
- Expo
- TypeScript
- Expo Router

## Kurulum

```bash
npm install
npx expo start --web
```

## Proje Yapısı

- `src/app/` — Ekranlar ve yönlendirme
- `src/components/` — Yeniden kullanılabilir bileşenler
- `src/data/` — Örnek arıza verileri
